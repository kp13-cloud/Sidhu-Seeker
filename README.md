📦 Installation

Clone the repository:

git clone https://github.com/kp13-cloud/Sidhu-Seeker.git
cd Sidhu-Seeker

Install the required dependencies according to the project's documentation:

pkg update
pkg install python git

🚀 Usage

Run the program from the project directory:

cd ~/Sidhu-Seeker
python seeker.py

Use the program only in an authorized test environment.

For example, you can use your own device or a local security-testing lab to understand how the application works.

Before using any feature, review the source code and documentation:

cat README.md
